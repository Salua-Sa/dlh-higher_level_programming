# DLH Higher Level Programming

This repository contains Python programming projects from the Digital Learning Hub AI Academy


## Project Structure

| Folder | Description |
|---|---|
| [python-hello_world](./python-hello_world) | Python interpreter, printing text and variables, strings, indexing, slicing, and basic style |
| [python-if_else_loops_functions](./python-if_else_loops_functions) | Conditions, loops, functions, return values, scope, comments, and arithmetic operators |
| [python-import_modules](./python-import_modules) | Importing functions, creating modules, using `dir()`, command line arguments, and `if __name__ == "__main__"` |
| [python-data_structures](./python-data_structures) | Lists, tuples, sequences, slicing, stacks, queues, list comprehensions, packing and unpacking |
| [python-more_data_structures](./python-more_data_structures) | Sets, dictionaries, lambda functions, `map`, `filter`, and `reduce` |
| [python-exceptions](./python-exceptions) | Errors, exceptions, `try`, `except`, `raise`, and cleanup actions |
| [python-classes](./python-classes) | Classes, objects, attributes, methods, `self`, `__init__`, encapsulation, and properties |
| [python-more_classes](./python-more_classes) | Class attributes, instance attributes, `__str__`, `__repr__`, class methods, static methods, and advanced OOP concepts |
| [python-input_output](./python-input_output) | Opening, reading, writing files, `with`, JSON, serialization, deserialization, and command line parameters |
| [python-serialization](./python-serialization) | Serialization, marshaling, JSON, pickle, and data persistence |

## Main Topics

- Python basics
- Strings and slicing
- Conditions and loops
- Functions and scope
- Modules and imports
- Command line arguments
- Lists and tuples
- Sets and dictionaries
- Error handling
- Object-oriented programming
- File input/output
- JSON and serialization\deserialization

## Learning Goal

The goal of this repository is to build strong Python fundamentals through practical projects and gradually move from simple scripts to structured object-oriented programs.
